Sistema de Relatório Técnico

Resumo

Aplicação web progressiva (PWA) em React + JavaScript para geração de relatórios técnicos de engenharia civil. Permite criar, editar e exportar relatórios de vistoria predial em PDF com fotos lado a lado, editor de imagens, parecer técnico automatizado e histórico por pastas. Funciona offline; Firebase Hosting serve os ficheiros estáticos.

Funcionalidades principais

  • 3 tipos de relatório: Pessoa Física, Condomínio, Empresa
  • Formulário dinâmico conforme o tipo selecionado
  • Upload de fotos com compressão automática
  • Editor de fotos embutido e comparativo no PDF
  • Parecer técnico com modelos pré-definidos
  • Histórico organizado por mês e pastas
  • Assinatura digital via canvas
  • Offline / Client-side com localStorage

Tecnologias

Linguagem: JavaScript (ES6+)
Framework: React 18 (Vite)
PDF: jsPDF
Imagens: Canvas API + compressão
Storage: localStorage
Host: Firebase Hosting
